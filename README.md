# Path

Path is an interactive algorithm visualization playground built to make fundamental computer-science algorithms visually legible, explorable, and dramatic.

The initial focus is sorting and searching, but the architecture is intended to expand into trees, graphs, pathfinding, and other step-driven algorithms.

## Product direction

Path should feel like an algorithm laboratory rather than a classroom bar-chart demo:

- deterministic step-by-step playback
- timeline scrubbing and replay
- side-by-side algorithm comparison
- multiple visualization modes
- live operation metrics
- responsive, high-performance motion
- educational explanations without getting in the way of the visuals

Path is also the first real project used to prove the [Fugue](https://github.com/JohnnyZLi/Fugue) multi-session engineering workflow.
